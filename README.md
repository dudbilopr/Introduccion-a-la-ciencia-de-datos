# Introducción a la Ciencia de Datos

**Docente:** Dudbil Olvasada Pabón Riaño · **Programa:** Ciencia de Datos, Universidad Autónoma de Bucaramanga (UNAB) · **Código:** 19001 · 3 créditos · 16 semanas

Material interactivo del curso: presentaciones, guías de laboratorio, cuadernos de Colab, retos gamificados y actividades de inmersión en inglés (EMI). Sitio: abra `index.html` (o la página de GitHub Pages del repositorio) y elija la semana.

## Cómo está organizado

| Ruta | Contenido |
|---|---|
| `index.html` | Aplicación del curso: cada semana muestra solo las pestañas que tiene. |
| `Semanas/Semana_N/` | Material de la semana N. |
| `Semanas/Datos/` | Datos reales del curso, con su fuente y licencia en [`FUENTES.md`](Semanas/Datos/FUENTES.md). |
| `Semanas/assets/puntos/` | Motor propio de presentaciones, guías y actividades EMI. |
| `Semanas/recursos/` | Banco de preguntas de las semanas 1 a 6. |

En las presentaciones: flechas para avanzar, **F** pantalla completa, **L** tema claro u oscuro, **N** notas del docente.

## Acuerdos de clase

1. Las clases inician a las 7:00. Se respeta el tiempo de los demás.
2. Hay descansos cognitivos en cada sesión.
3. Inmersión EMI de 10 minutos en inglés técnico en cada clase.
4. Espacio psicológicamente seguro: todas las preguntas son válidas.
5. Comunicación por el espacio del curso en Gmail.
6. El uso de IA se declara siempre: herramienta, para qué, prompt, versión del modelo y qué verificó usted.
