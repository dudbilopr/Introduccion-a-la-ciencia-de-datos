## Sobre el Curso

Este repositorio centraliza el material interactivo web y actividades del curso **Introducción a la Ciencia de Datos**. El objetivo de esta clase es proporcionar una visión panorámica, herramientas esenciales (como GitHub y LLMNotebooks) y los fundamentos conceptuales necesarios para el futuro científico de datos.

## Reglas y Acuerdos de Clase

Para mantener un ambiente de aprendizaje óptimo, seguro y profesional, nos regimos por los siguientes acuerdos:

1. **Puntualidad:** Las clases inician puntualmente a las **7:00 AM**.
2. **Descansos Cognitivos:** Se implementarán pausas estratégicas para evitar la fatiga mental.
3. **Estrategia EMI (English as a Medium of Instruction):** Tendremos inmersiones de 10 minutos exclusivamente en inglés técnico para fortalecer el bilingüismo.
4. **Respeto:** Este es un espacio psicológicamente seguro. Todas las preguntas son válidas y el debate constructivo es bienvenido.
5. **Comunidad:** Gestionaremos dudas, recursos y comunicación constante a través de nuestro **Espacio en Gmail**.

## Herramientas Tecnológicas

- **GitHub:** Plataforma estándar de la industria para control de versiones y portafolio profesional.
- **LLMNotebook:** Asistencia con Inteligencia Artificial (Copiloto cognitivo) para acelerar el aprendizaje.
- **Mentimeter:** Herramienta interactiva para participación en tiempo real.
