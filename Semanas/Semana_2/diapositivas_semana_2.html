Glosario de Términos

  • Librería (Library): Colección de código preescrito que los programadores pueden usar para optimizar tareas.
  • Jupyter Notebook: Documento interactivo que combina código ejecutable, ecuaciones, visualizaciones y texto narrativo.
  • Datos Sintéticos: Información generada artificialmente en lugar de ser producida por eventos del mundo real, muy útil para pruebas y entrenamiento de algoritmos.

¿Qué es Python?

  • Lenguaje de programación de alto nivel.
  • Interpretado y multiparadigma.
  • Sintaxis clara y legible (casi como leer inglés).
  • El estándar actual en Ciencia de Datos e Inteligencia Artificial.

El Ecosistema

Python no trabaja solo. Se apoya en librerías:

  • Pandas: Manipulación y análisis de datos tabulares (como Excel pero con esteroides).
  • NumPy: Cálculo numérico y matricial.
  • Matplotlib/Seaborn: Visualización de datos.

Google Colab

  • Un entorno de Jupyter Notebook en la nube.
  • Cero Configuración: No requieres instalar nada localmente.
  • Permite intercalar código, resultados y texto explicativo (Markdown).
  • Se guarda automáticamente en Google Drive.

Pair Programming

Programación en parejas para el taller práctico.

Piloto: Escribe el código.
Copiloto: Revisa, busca errores y guía la lógica.

¡Cambiaremos roles a la mitad!

Generación de Datos Sintéticos

  • Simularemos ser analistas de una tienda sin datos históricos.
  • Generaremos registros aleatorios (productos, ventas, fechas) usando Python.
  • Convertiremos estos datos a un DataFrame de Pandas.
  • Analizaremos las métricas principales.

Conclusiones

  • Python es el lenguaje dominante en Ciencia de Datos gracias a su ecosistema abierto (Pandas, Numpy).
  • Google Colab elimina las barreras de configuración inicial y estandariza el entorno de desarrollo para todo el equipo.
  • El Pair Programming no solo mejora el código, sino que fomenta la comunicación de hallazgos analíticos.
