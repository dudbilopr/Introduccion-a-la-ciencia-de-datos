Estructuras Core

La forma en que organizas los datos antes de aplicar los algoritmos.

  • Listas (List): Colecciones ordenadas, mutables. [1, 2, 'tres']
  • Tuplas (Tuple): Colecciones ordenadas, inmutables. (1, 2)
  • Diccionarios (Dict): Colecciones clave-valor. {'nombre': 'Juan'}
  • Sets: Colecciones sin elementos duplicados. {1, 2, 3}

Listas vs Tuplas

La Lista (Mutable)


                            # Se define con corchetes
                            mi_lista = [10, 20, 30]
                            
                            # Puedo alterar sus elementos
                            mi_lista[0] = 99
                            print(mi_lista) 
                            # Salida: [99, 20, 30]

La Tupla (Inmutable)


                            # Se define con paréntesis
                            mi_tupla = (10, 20, 30)
                            
                            # ESTO LANZA UN ERROR:
                            mi_tupla[0] = 99
                            # TypeError: 'tuple' object does 
                            # not support item assignment

Se usan para retornar múltiples valores de una función o para proteger datos que no deben cambiar.

El Poder de los Diccionarios

"Si solo pudieras llevar una estructura de datos a una isla desierta, debería ser el Diccionario. Es la estructura fundamental de Python." — Data Science from Scratch 

                    # Se definen con llaves {clave: valor}
                    alumno = {
                        "nombre": "Pedro",
                        "calificaciones": [4.5, 3.8, 5.0],
                        "aprobado": True
                    }

                    # Búsqueda ultra-rápida (O(1))
                    print(alumno["calificaciones"])

Glosario EMI

  • String: Cadena de Texto.
  • Integer / Float: Entero / Decimal.
  • Boolean: Booleano (True/False).
  • List / Tuple / Dictionary: Lista / Tupla / Diccionario.
  • Loop (For/While): Bucle o Ciclo.
  • Function / Method: Función / Método.

Conclusiones

  • Python no prioriza el rendimiento puro de la máquina, prioriza el rendimiento del programador mediante código legible.
  • Los Jupyter Notebooks (Colab) son el lienzo iterativo donde los datos cobran vida sin compilar proyectos masivos.
  • Los Diccionarios y Listas son la base de casi toda estructura de datos compleja (como los DataFrames de Pandas).
