\subsection*{Parte A: Tipos de Datos (25\%)}
Declare las siguientes variables en Python y utilice la función \texttt{type()} para imprimir el tipo de dato de cada una:
\begin{itemize}
    \item \texttt{producto = "Laptop Gamer"}
    \item \texttt{precio = 1250.50}
    \item \texttt{cantidad = 15}
    \item \texttt{en\_stock = True}
\end{itemize}

\subsection*{Parte B: Colecciones (25\%)}
Cree una \textbf{lista} llamada \texttt{ventas\_semana} que contenga las siguientes cantidades: \texttt{5, 12, 8, 20, 3}.
Luego, utilizando funciones nativas de Python (como \texttt{sum()}, \texttt{max()}, \texttt{min()}):
\begin{enumerate}
    \item Calcule e imprima el total de ventas de la semana.
    \item Calcule e imprima el día de mayor y menor venta.
\end{enumerate}

\subsection*{Parte C: Introducción a Pandas (50\%)}
A partir del siguiente diccionario en Python, conviértalo en un \textbf{DataFrame} utilizando Pandas y expórtelo como un archivo CSV llamado \texttt{inventario.csv}.

\begin{verbatim}
import pandas as pd

datos = {
    'Producto': ['Mouse', 'Teclado', 'Monitor', 'Cable HDMI'],
    'Precio': [15.0, 45.0, 200.0, 5.0],
    'Stock': [100, 50, 20, 200]
}
\end{verbatim}

Una vez convertido a DataFrame, calcule en una nueva columna el valor total del inventario por producto (Multiplicando Precio x Stock).
