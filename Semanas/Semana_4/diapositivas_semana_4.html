Glosario de Términos

Outlier: Valor atípico que se aleja significativamente de las demás observaciones.

Imputación: Proceso de sustituir valores faltantes en un dataset por valores estimados.

Seaborn: Librería estadística de Python construida sobre Matplotlib con estética superior.

Plotly: Librería para gráficos interactivos (zoom, hover) ideal para presentaciones y web.

Visual Vocabulary

  • Scatter Plot: Shows relationship between two numerical variables.
  • Bar Chart: Compares categorical data.
  • Box Plot: Displays distribution and outliers.

Pro-Tip:

Never use pie charts for more than 3 categories. Humans are bad at estimating angles.

Pandas: El Arte de Limpiar

Antes de graficar, los datos deben ser puros.


import pandas as pd
df = pd.read_csv("datos_salud.csv")

# ¿Cuántos datos nulos tenemos por columna?
print(df.isnull().sum())

Tratamiento de Nulos (NaN)


# Opción 1: Eliminar las filas con nulos (Peligroso si pierdes mucha data)
df_limpio = df.dropna()

# Opción 2: Imputar usando la mediana (Robusto contra outliers)
mediana_edad = df['edad'].median()
df['edad'] = df['edad'].fillna(mediana_edad)

Nota del Científico: Siempre prefiere la mediana sobre la media si la variable está muy sesgada (distribución asimétrica).

Matplotlib & Seaborn

La base visual de Python.


import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style="whitegrid") # Diseño limpio profesional

Gráficos de Distribución


plt.figure(figsize=(8,5))
sns.histplot(data=df, x="ingresos", 
             kde=True, color="#003865")
plt.title("Distribución de Ingresos")
plt.xlabel("Dólares")
plt.ylabel("Frecuencia")
plt.show()

Visualiza cómo se concentran los datos.

Identificando Outliers (Boxplot)


plt.figure(figsize=(10,4))
sns.boxplot(x=df["salario"], color="#E85C0B")
plt.title("Detección de Valores Atípicos")
plt.show()

Todo punto más allá de los bigotes del Boxplot es matemáticamente un outlier (1.5 * IQR).

Plotly Express

Eleva tus gráficos estáticos a dashboards interactivos profesionales.


import plotly.express as px

fig = px.scatter(df, x="gdp", y="life_expectancy", 
                 color="continent", hover_name="country",
                 log_x=True, size_max=60)
fig.show()

¿Por qué usar Plotly?

  • Soporta tooltips (Hover), revelando los datos detrás de cada punto.
  • Pan, Zoom y selecciones (Lasso) nativos.
  • Se exporta fácilmente como un archivo HTML independiente para incrustarlo en la web.

Chartjunk (Basura Gráfica)

Término acuñado por Edward Tufte que se refiere a todos los elementos visuales en gráficos informativos que no son necesarios para comprender los datos o que distraen al espectador (ej. fondos complejos, 3D innecesario, colores extremos).
