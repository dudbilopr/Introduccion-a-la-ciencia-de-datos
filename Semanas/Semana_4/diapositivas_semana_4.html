Limpieza en Acción (Pandas)


import pandas as pd
import numpy as np

# Cargar dataset de Kaggle (Ejemplo: Titanic)
df = pd.read_csv("titanic.csv")

# 1. Identificar nulos
print(df.isnull().sum())

# 2. Imputar nulos en la Edad con la mediana
mediana_edad = df['Age'].median()
df['Age'].fillna(mediana_edad, inplace=True)

# 3. Eliminar duplicados absolutos
df.drop_duplicates(inplace=True)
Pro-Tip: Nunca elimines datos con dropna() a menos que sean menos del 5% del total de tu dataset. ¡Estás perdiendo información valiosa!

Imputación de Datos

La imputación es el proceso de reemplazar los datos faltantes (NaN) con valores estadísticamente plausibles para no perder la fila entera.

  • Media: Usada para variables numéricas con distribución normal (sin sesgo).
  • Mediana: Usada para variables numéricas con valores extremos (outliers).
  • Moda: Usada para variables categóricas (ej. Género, Ciudad).
df['salario'].fillna(df['salario'].median(), inplace=True)

Outliers (Valores Atípicos)

Son observaciones que se desvían drásticamente de las demás observaciones. Pueden indicar variabilidad natural, errores de medición, o novedades.

La forma más eficiente de detectarlos visualmente es mediante un Gráfico de Cajas y Bigotes (Boxplot).

sns.boxplot(x=df["ingresos"])
plt.show()

Chartjunk (Basura Gráfica)

Término acuñado por Edward Tufte que se refiere a todos los elementos visuales en gráficos que NO son necesarios para comprender los datos (ej. fondos complejos, 3D falso, cuadrículas pesadas, colores extremos).

Regla de Oro: Maximizar la proporción de "Tinta de Datos" (Data-Ink ratio). Borra todo lo que no represente un dato.
