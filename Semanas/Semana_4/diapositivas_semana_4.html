Data Janitor Work

"Los Científicos de Datos gastan el 80% de su tiempo limpiando y organizando datos, y el otro 20% de su tiempo quejándose sobre la limpieza de los datos." — Cleaning Data for Effective Data Science

¿Qué limpiamos?

  • Datos Faltantes (NaN): ¿Los borramos? ¿Los imputamos con el promedio?
  • Inconsistencias: "Nueva York", "New York", "NY". (Son la misma entidad).
  • Formatos: Fechas como strings ("12/10/2021" vs "10-12-21").
  • Outliers: Valores absurdos (Ej. Edad = 1500 años).

Manejo de Valores Faltantes en Pandas

Las dos estrategias principales para enfrentar los NaN (Not a Number).

1. Eliminación (Drop)


                        # Elimina cualquier fila que tenga un NaN
                        df_limpio = df.dropna()

                        # Elimina la columna entera si tiene NaN
                        df_columnas = df.dropna(axis=1)

Peligro: Podrías borrar la mitad de tu base de datos si eres demasiado estricto.

2. Imputación (Fill)


                        # Llenar con un valor por defecto (0)
                        df['salario'] = df['salario'].fillna(0)

                        # Llenar con la media (promedio)
                        media_salario = df['salario'].mean()
                        df['salario'].fillna(media_salario)

Ventaja: Mantienes las filas, pero assumes un valor estadístico que añade ruido artificial.

SQL Básico

SQL (Structured Query Language) es el estándar industrial para hablar con Bases de Datos Relacionales.


                        SELECT nombre, salario
                        FROM Empleados
                        WHERE salario > 50000
                        ORDER BY salario DESC;

SQL es Declarativo: Le dices a la base de datos QUÉ quieres, no CÓMO conseguirlo.

Equivalencias: SQL vs Pandas

La filosofía relacional vive dentro de Pandas.

Operación SQL Pandas
SELECT SELECT col1, col2 FROM df df[['col1', 'col2']]
WHERE SELECT * FROM df WHERE col1 > 10 df[df['col1'] > 10]
GROUP BY SELECT col1, SUM(col2) GROUP BY col1 df.groupby('col1')['col2'].sum()
ORDER BY ORDER BY col1 DESC df.sort_values('col1', ascending=False)
JOIN / Merge SELECT * FROM t1 JOIN t2 ON t1.id = t2.id pd.merge(t1, t2, on='id')

Glosario EMI

  • Data Cleansing: Limpieza de datos.
  • Missing Values (NaN): Valores faltantes.
  • Imputation: Imputación (Rellenar vacíos).
  • Query: Consulta (en SQL).
  • Join / Merge: Unión de tablas.
  • Outlier: Valor atípico extremo.

Conclusiones

  • La calidad del modelo predictivo nunca superará la calidad de los datos de entrada. La limpieza es la fase más crítica.
  • Pandas adopta y emula el poder de SQL mediante operaciones relacionales como merge y groupby, permitiendo transformar datos estructuralmente.
  • Eliminar datos faltantes es fácil pero peligroso; imputarlos es inteligente pero introduce ruido artificial. El Data Scientist debe equilibrar ambos.
