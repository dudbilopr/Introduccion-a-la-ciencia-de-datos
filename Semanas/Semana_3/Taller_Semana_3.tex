\section*{\textcolor{unabblue}{1. Objetivo del Taller}}
Integrar el conocimiento de control de flujo (ciclos iterativos y condicionales) con el análisis de grandes volúmenes de datos utilizando la librería Pandas.

\subsection*{Reto 1: Limpieza con Ciclos (30\%)}
Usted recibe la siguiente lista de nombres, los cuales fueron ingresados erróneamente por un sistema antiguo (con mayúsculas, minúsculas y espacios extra):

\begin{verbatim}
empleados_sucios = ["   aNa perEz  ", "CARLOS Gomez", " lucia fernandez "]
\end{verbatim}

Utilizando un \textbf{ciclo for} y funciones de texto en Python (como \texttt{strip()} y \texttt{title()}), genere una nueva lista llamada \texttt{empleados\_limpios} que contenga los nombres formateados correctamente (Ej. "Ana Perez").

\subsection*{Reto 2: Construcción del DataFrame (30\%)}
Utilizando la lista \texttt{empleados\_limpios} del Reto 1, y la siguiente información adicional, construya un DataFrame de Pandas:
\begin{itemize}
    \item \textbf{Salario:} [3500, 4200, 2800]
    \item \textbf{Departamento:} ['Ventas', 'TI', 'Ventas']
\end{itemize}
Imprima el DataFrame resultante en pantalla.

\subsection*{Reto 3: Lógica y Filtrado (40\%)}
Con el DataFrame construido en el Reto 2, escriba código en Pandas para responder a las siguientes preguntas:
\begin{enumerate}
    \item ¿Cuál es el salario promedio de la empresa?
    \item Filtre el DataFrame para mostrar \textbf{solo} a los empleados que trabajan en el departamento de "Ventas".
    \item (Bonus) Escriba un código condicional (\texttt{if}) que verifique si el salario promedio es mayor a 3000, imprimiendo "Salario competitivo" en caso afirmativo, y "Revisar tabulador" en caso negativo.
\end{enumerate}
