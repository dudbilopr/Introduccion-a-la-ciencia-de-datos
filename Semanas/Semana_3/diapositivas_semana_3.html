Numpy: El Motor Bajo el Capó

"NumPy es la base sobre la cual se construye casi todo el ecosistema de ciencia de datos en Python. Su secreto no es ser Python, sino esconder código ultra-optimizado en lenguaje C detrás de una interfaz amigable." — NumPy Cookbook

El Array (ndArray)

A diferencia de las Listas de Python (donde cada elemento puede ser de un tipo distinto y están dispersos en la memoria), un Array de Numpy asegura que todos los elementos son del mismo tipo y se guardan en un bloque contiguo de RAM.

La Ley de la Vectorización

La regla de oro del Data Scientist: Evita los bucles for.

Bucle Tradicional (Lento)


                            # Multiplicar cada elemento por 2
                            lista = [1, 2, 3, 4, 5]
                            nueva_lista = []
                            for x in lista:
                                nueva_lista.append(x * 2)

Python interpreta cada línea, verifica los tipos de datos en cada paso. Lento y costoso.

Vectorización Numpy (Rápido)


                            import numpy as np

                            # Multiplicar el array entero a la vez
                            array = np.array([1, 2, 3, 4, 5])
                            nuevo_array = array * 2

El cálculo se empuja a un bucle interno en C. Se procesa como un bloque de memoria único.

Pandas: Tu Hoja de Cálculo en Esteroides

Pandas está construido directamente sobre NumPy, pero añade Índices y Etiquetas.

Mientras NumPy requiere que sepas que la edad está en la columna 3, Pandas te permite llamarla por su nombre: df['edad'].

Series (1D)

Una sola columna de datos. Como una lista con superpoderes y un índice a su izquierda.

DataFrame (2D)

Un diccionario de Series. Piensa en él como una tabla completa de Excel cargada en RAM.

Ingesta de Datos (I/O)

La capacidad de Pandas para tragar casi cualquier formato de datos crudos.


                        import pandas as pd

                        # Desde un archivo local
                        df_csv = pd.read_csv("datos.csv")
                        df_excel = pd.read_excel("ventas.xlsx")

                        # ¡Directamente desde la web!
                        url = "https://miservidor.com/datos.json"
                        df_json = pd.read_json(url)

                        # Leer tablas HTML directamente de Wikipedia
                        tablas = pd.read_html("https://wikipedia.org/wiki/Poblacion")

Conclusiones

  • El bucle for en Python es nuestro enemigo cuando manejamos Big Data. La Vectorización con Numpy es la solución técnica subyacente.
  • Pandas es nuestra navaja suiza para ingerir archivos CSV, Excel o APIs web e indexarlos para un manejo rápido.
