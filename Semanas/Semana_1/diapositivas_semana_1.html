¿Qué es la Ciencia de Datos?

"La Ciencia de Datos es la disciplina de extraer conocimiento y descubrimientos a partir de información bruta, utilizando un enfoque holístico que mezcla programación, matemáticas y contexto de negocio. No se trata de qué algoritmos conoces, sino de qué problemas puedes resolver." — What is Data Science (O'Reilly Media)

El Cambio de Paradigma

  • Analítica Clásica: "¿Qué pasó en el pasado?" (Reportes, BI).
  • Ciencia de Datos: "¿Por qué pasó? ¿Qué pasará después? ¿Cómo lo optimizo?" (Modelado Predictivo y Prescriptivo).

  • Hacking Skills: No es hackear bancos. Es saber programar, manipular archivos, raspar la web (Python/SQL).
  • Math & Stats: Rigor matemático para no dejarse engañar por números ruidosos y crear modelos.
  • Domain Expertise: Conocer el negocio. Un buen algoritmo en el negocio equivocado es inútil.

Las Zonas de Peligro

La intersección incompleta de estas tres áreas crea perfiles funcionales, pero a veces peligrosos.

CS + Domain

La Zona de Peligro

Personas que saben programar y conocen el negocio, pero aplican algoritmos sin entender la estadística subyacente. ¡Producen modelos que parecen funcionar pero mienten!

Math + CS

Machine Learning

Construyen sistemas asombrosos (ej. reconocimiento facial), pero si carecen de Domain Expertise, rara vez resuelven el problema real de la empresa.

Ecosistema de Roles

Rol Enfoque Principal Herramientas Clave
Data Engineer Construye la tubería (pipelines) para que los datos fluyan limpios y escalables. SQL, Spark, AWS/GCP, Airflow
Data Scientist Encuentra patrones complejos, entrena modelos predictivos y experimenta estadísticamente. Python (Pandas, Scikit-Learn), R
Data Analyst Responde preguntas descriptivas rápidas del negocio usando visualizaciones. Excel, PowerBI, Tableau, SQL

El Ciclo de Vida (CRISP-DM)

  1. Entendimiento del Negocio: ¿Qué resolvemos?
  2. Entendimiento del Dato: ¿Qué tenemos?
  3. Preparación del Dato: Limpieza (Toma el 80% del tiempo).
  4. Modelado: Aplicar Machine Learning.
  5. Evaluación: ¿Es confiable?
  6. Despliegue: Poner en producción.

Glosario EMI

  • Data Science: Ciencia de Datos.
  • Domain Expertise: Experiencia en el Dominio / Negocio.
  • Hacking Skills: Habilidades de Programación.
  • Pipeline: Tubería de Procesamiento.
  • Deployment: Despliegue.
  • Raw Data: Datos Crudos.

Conclusiones

  • La herramienta no hace al científico; la forma estructurada de pensar y resolver problemas sí.
  • El equilibrio perfecto requiere Programación, Matemáticas y un entendimiento profundo del contexto de negocio.
  • Existen roles diferenciados: no tienes que hacerlo todo tú solo. La ingeniería de datos y el análisis de datos son ramas aliadas.
